# Credit Card Customer Segmentation

## Problem Type

This is an **unsupervised learning** problem because the dataset does not contain a target label or predefined customer category.

The dataset includes credit card customer behavior features such as:

- `BALANCE`
- `PURCHASES`
- `ONEOFF_PURCHASES`
- `INSTALLMENTS_PURCHASES`
- `CASH_ADVANCE`
- `CREDIT_LIMIT`
- `PAYMENTS`
- `MINIMUM_PAYMENTS`
- `TENURE`
- Other transaction and frequency-related features

The `CUST_ID` column was removed because it is only an identifier and does not provide useful behavioral information for clustering
