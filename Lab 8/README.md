
# K Nearest Neighbors Assignment
## This project implements the K-Nearest Neighbors (KNN) algorithm to perform classification on a dataset. The goal is to understand how instance-based learning works and evaluate model performance using different values of K.

## How it works:-
- Explore the dataset
- Preprocess the data
- Split data into training and testing sets
- Train KKN model using different K values
- Evaluate the performance based on the accuracy score and confusion matrix
- Selection of Optimal K
